# Initial program — v0.2.3 through v0.5

## Objective and outcome

The initial program advanced the repository from its v0.2.3 baseline through
the completed v0.3, v0.4, and v0.5 objectives. It established persistence and
world loading, simulation and settlement foundations, NPC identity and
cognition, the NPC information boundary, local-model proposals and the action
gateway, conversations and councils, and privileged read-only HTTP inspection.

Task 14 performed the v0.5 release closeout after the focused Task 14b release
version correction. Task 14a then reorganized the completed execution history
without changing implementation or release behavior.

## Historical order

The authoritative historical order is preserved in the
[cross-milestone index](README.md#initial-program-archive). It links every plan,
saved prompt, correction artifact, and report in the
[`initial_v0_2_3_to_v0_5/`](initial_v0_2_3_to_v0_5/) directory.

The sequence begins with Task 01 baseline reconciliation, proceeds through the
v0.3 and v0.4 foundations and the v0.5 AI-layer work, closes the release with
Task 14 and Task 14b, and ends with the Task 14a archive migration.

## Archive policy

The milestone directory is an immutable planning archive. Future edits are
limited to link repairs and factual corrections; new implementation work must
belong to its own milestone. Historical filenames, globally unique task
numbers, and the established `-prombt.md` spelling are preserved.

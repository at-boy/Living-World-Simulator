# LN09f6a — Saved trace evidence ZIP implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox tracking.

**Goal:** Export one attempt's exact saved LLM call evidence to a new private ZIP for later analysis, without changing the source.
**Architecture:** Reuse bounded trace readers at one authenticated journal prefix. Serialize canonical call metadata and deduplicated verified opaque bodies; validate a private staged ZIP and publish it exclusively. Local CLI only, no HTTP export route or simulation owner.
**Tech Stack:** Python >=3.11, stdlib zipfile/hashlib/tempfile/os, existing trace reader and CLI.
**Spec:** Approved live-runtime analysis/export execution, docs/trace_analysis.md and docs/superpowers/specs/2026-10-19-live-npc-runtime-design.md. All relevant root export decisions are materialized below; no historical task reconstruction required.

## Global Constraints

- RuntimeService solewriter; managers mutate/systems behavior/eventsimmutable; NPC contexts filtered and LLM output untrusted through gateway.
- No world reconstruction/validation, catalog.attempts/open_attempt, lease probing/acquisition, runtime/provider/preflight/reservation/runloop, schema/reader/HTTP changes.
- Source bytes/mtimes remain unchanged; output must be outside source catalog. Preserve user output, branches/worktrees and owner edit. Root owns architecture/common docs/Git/full gates/native package proof.
- This bundle is local trace evidence, not a reopenable world catalog, authenticated ancestor closure or uncommitted spool capture. Never manufacture missing bodies, backend/model/timings or legacy evidence.

## Review Focus

- Pending/legacy/incomplete/reused/observed-empty evidence retains exact distinctions and original timing/provenance.
- Appends during export do not extend the captured prefix; selected corruption fails before final publication.
- Output traversal/overlap/existing files and failure cleanup never mutate source or foreign output.
- Finite limits/cancellation fail with closed safe codes; no partial final ZIP before publication.
- Actual CLI/installed package produces deterministic valid ZIPs whose raw bytes/hash manifest can be checked independently.

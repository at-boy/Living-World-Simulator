# Subagent execution plans

This directory is the cross-milestone index for isolated task plans, saved
prompts, correction instructions, and approved orchestrator reports. Task
numbers remain globally unique. A documented task is not authorized merely
because it appears here.

## Milestones

- [Initial program: v0.2.3 through v0.5](initial_v0_2_3_to_v0_5.md)
- [v0.6: autonomous founding settlement](v0_6.md)

Future milestones use one overview Markdown file beside one directory of task
artifacts. The branching relationship is documented in
[the development workflow](../development_workflow.md).

## Delivery rule

Every implementation task requires a plan, saved `-prombt.md`, truthful report,
independent review, boundary audit, `make`, `make examples`, and
`git diff --check`. The engine authority and NPC information boundary remain
non-negotiable.

# v0.6 — Autonomous founding settlement

## Objective

The proposed v0.6 milestone is an end-to-end autonomous founding-settlement
vertical slice. A small founding group should be able to establish shelter,
food, storage, and a homeland trade route through engine-owned goals, needs,
work, and settlement-stage criteria while preserving simulation authority and
the NPC information boundary.

The acceptance target is to start one command, run the canonical scenario for
a bounded period without operator intervention, inspect why it succeeded,
stalled, or failed, and replay the same configured seed. The complete scope and
dependency order are in the
[post-v0.5 settlement-evolution roadmap](../post_v05_settlement_evolution_roadmap.md#v06--autonomous-founding-settlement-vertical-slice).
